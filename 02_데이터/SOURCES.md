# 데이터 출처

모든 파일은 공공데이터포털(data.go.kr) 파일데이터를 `scripts/00_download_data.py`로 받았다. 로그인, 활용신청, 인증키 없이 웹페이지의 [다운로드] 버튼과 같은 절차로 받았고, 원본은 `02_데이터/raw/`에 손대지 않고 저장했다. 데이터셋별 포털 메타데이터 원문은 `02_데이터/raw/_meta/*.json`에 함께 저장했다.

- 받은 날짜: 2026-11-06 (전 파일 공통)
- 이용허락범위: 전 데이터셋 "이용허락범위 제한 없음", 무료
- 인코딩: 전 파일 cp949 (점검 결과는 `02_데이터/raw_profile.md`)

## 2. [필수, 보조] 한국전력거래소_연료원별 전력거래량

- 제공기관: 한국전력거래소 (수집 부서: 시장정산팀)
- URL: https://www.data.go.kr/data/15081098/fileData.do
- 갱신 주기: 수시 (1회성 데이터). 포털 설명: "이후 데이터는 '한국전력거래소_연료원별 시간대별 설비용량 및 전력거래량' 목록에서 연간 갱신하여 제공"
- 파일명: `한국전력거래소_연료원별 전력거래량_20231231.csv`
- 기간: 2023-11-01 ~ 2023-12-31 (현재 게시판은 2개월분만 수록), 30,744행, 연료원 21종
- 포털 등록일 / 수정일: 2024-12-11 / 2025-11-17
- 포털 설명 요지: 한국전력공사와 직접 거래하는 발전기, 자가용 등은 포함하지 않음(전기사업법 시행령 제19조 1항 2호).
- 용도: 1번 2023년판과 교차 검증용. 2023-11~12월 29,280개 (일자, 시간, 연료원) 값이 완전히 일치함을 확인(`raw_profile.md` 교차 점검).

## 참고: 찾았지만 받지 않은 관련 데이터셋

2024년판의 전체 전원 시간별 자료를 대신할 데이터셋을 포털에서 찾아봤지만, 전국 단위로 전 연료원을 시간별로 담은 2024년 자료는 찾지 못했다.

- 한국전력거래소_연료원별 일별 전력거래량(MWh) (https://www.data.go.kr/data/15153668/fileData.do, 20241231판): 이름상 일별 자료여서 시간별 분석에 맞지 않음
- 한국전력거래소_시간별 발전량 (https://www.data.go.kr/data/15065387/fileData.do): 20211231판까지만 있음
- 한국전력거래소_비중앙발전기 연료원별 일별 시간대별 전력거래량 (https://www.data.go.kr/data/15157963/fileData.do): 비중앙발전기만 다룸
- 전력거래소 홈페이지 실시간 전력수급현황 (https://www.kpx.or.kr/powerSource.es?mid=a10606030000): 5분 단위 '태양광(PPA,추정)', '태양광(BTM,추정)', 2024-11-23부터, 한 번에 최대 31일 엑셀 다운로드. 2025년 시간별 비계량 태양광 모양을 반영할 수 있으나 이번에는 쓰지 않음
- 자가용/한전PPA/전력시장내외 태양광 출력 추계(MW) (15154441, 15154489, 15154484): 시간별이나 포털에는 샘플만 있고 전체 자료는 한국전력공사 데이터안심구역(서울/나주) 방문 이용
