# 02. DVFS 모델의 정적 전력 비율 기본값을 0.33으로 한 이유

## 배경

DVFS 모델은 전력 = 정적 전력 + 동적 전력 × f³이다. 정적 전력 비율은 CPU 주파수를 낮춰도 줄지 않는 전력의 비율이고, D 정책의 절감률을 크게 좌우한다(0.21이면 49.1%, 0.5면 21.7%). 처음에는 근거 없는 0.4를 썼다.

## 선택지

- 0.21: SPECpower_ssj2008 2023~2026년 공개 결과 263건(1노드, 1~2소켓 Xeon/EPYC)의 active idle / 100% 부하 전력 비율 중앙값 0.213. 직접 다시 계산해 확인했다
- 0.33: Barroso 외, "The Datacenter as a Computer" 3판(2018). CPU가 최대 부하 전력의 2/3를 쓴다. 따라서 CPU 밖 1/3은 DVFS로 줄일 수 없다
- 0.5: Barroso & Hölzle(2007), 유휴 서버도 최대 전력의 약 절반을 쓴다(옛 서버)

## 결정

기본값은 0.33으로 하고, 민감도로 0.21과 0.5를 함께 계산한다. 발표에서는 "모델 가정에 따라 22~49%, 기본 가정 37%"로 쓴다.

## 이유

- 유휴 전력 비율(0.21)은 주파수와 무관한 전력의 하한이다. 유휴 상태 CPU는 깊은 절전 상태라, 부하 중 최저 주파수일 때보다 전력이 적다. 이 값을 기본으로 쓰면 DVFS 효과를 크게 잡는다
- 0.33은 출처가 있고, 하한과 옛 서버 상한 사이에 있는 보수적인 값이다
- 사용자가 승인했다(2단계 보완)
