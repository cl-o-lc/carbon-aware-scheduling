# 01. 탄소 곡선 기준을 A안(전력시장 거래량)으로 한 이유

## 배경

전력거래소 거래량에는 한전 직접 거래(PPA)와 자가용 태양광이 빠져 있어 태양광 비중이 2.3%(2025년)로 실제보다 낮다. EPSIS 월별 자료로 보면 시장 밖 태양광을 합친 전체 태양광은 시장 태양광의 3.60배(2025년)다. 이를 반영하면 한낮의 탄소 하락이 커진다.

## 선택지

- A안: 전력시장 거래량만 쓴다(보수적 하한)
- B안: 전력거래소 홈페이지의 5분 단위 PPA·자가용 태양광 추정치를 시간별로 집계해 더한다(실제 전력망 기준)
- B안 대체: EPSIS 월별 배수로 시장 태양광을 늘린다(시간별 모양은 시장 태양광과 같다고 가정)

## 결정

A안을 주 결과로 한다. EPSIS 월별 배수 버전은 민감도로 두고, 발표에서는 "시장 거래량 기준 9.1%, 시장 밖 태양광을 월별 비율로 반영하면 약 13.9%(가정)"처럼 범위로 쓴다.

## 이유

- 사용자는 처음에 B안(5분 단위 실측 집계)을 주 결과로 정했다. 그런데 엑셀 다운로드가 스크립트로는 웹 방화벽에 막혔고, 사용자가 브라우저로 시도해도 HTTP 503이었다(2026-11-06). 실측 근거 없이 월별 배수 가정을 주 결과로 쓰지 않는다
- 공개 데이터만으로 누구나 재현할 수 있다
- 시장 밖 태양광이 빠진 만큼 효과를 작게 잡은 값이라 과장 위험이 없다
- 화면 조회 표본 하나(2025-03-20 12:00)에서는 월별 배수가 시장 밖 태양광을 조금 크게 잡는 쪽이었다(표본 3.39배, 3월 배수 3.65배). 표본이 하나라 결론은 내리지 않았다
