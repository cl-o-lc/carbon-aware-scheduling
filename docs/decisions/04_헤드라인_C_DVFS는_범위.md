# 04. 헤드라인을 C(9.1%)로 두고 DVFS는 범위로 쓴 이유

## 배경

연간 절감률(현재 관행 A 대비, 시장 거래량 기준)은 다음과 같다.
- C(스케줄링만): 9.1%
- D(C + DVFS): 기본 가정에서 37.2%, 정적 전력 가정에 따라 21.7~49.1%

D가 훨씬 크지만, 절감의 대부분은 주파수를 낮춰 에너지 자체를 줄인 효과다(C 대비 에너지 33.6% 감소). 이 크기는 f³ 전력 모델과 정적 전력 비율 가정에 크게 기댄다.

## 선택지

- D(37%)를 헤드라인으로 쓴다
- C(9.1%)를 헤드라인으로 쓰고 D는 범위로 한 장만 쓴다

## 결정

헤드라인은 C 9.1%로 한다. DVFS는 9장 한 장에서 "DVFS를 더하면 전체 절감이 모델 가정에 따라 22~49%, 기본 가정 37%"로 쓴다. D는 A 대비 전체 절감률(스케줄링 효과 포함)이라는 점을 함께 밝힌다.

## 이유

- C는 실제 탄소 곡선과 작업 시간 이동만으로 나온 값이라 가정이 적다
- D는 단순 모델(f³, 고정 정적 비율, 고정 메모리 바운드 비율)에 달려 있다. 실제 CPU는 전압을 일정 수준 아래로 못 내리고 주파수 단계도 다르다
- 프로젝트의 핵심 메시지인 "언제 돌리느냐"와 "얼마나 기다릴 수 있느냐"는 C의 결과로 설명된다
- 사용자가 승인했다
